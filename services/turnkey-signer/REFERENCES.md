# Turnkey integration references

- [Turnkey Sign Transaction API](https://docs.turnkey.com/api-reference/activities/sign-transaction): The server SDK exposes `apiClient().signTransaction` with `signWith`, a raw unsigned transaction, and `TRANSACTION_TYPE_SOLANA`; the result includes `activity.result.signTransactionResult.signedTransaction`. Turnkey API calls use server-side P-256 API-key credentials.
- [Turnkey Solana transactions](https://docs.turnkey.com/features/networks/solana-transactions): Standalone `signTransaction` signs but does not broadcast. The unsigned payload is a complete serialized Solana transaction in hex, including empty signature slots. The signer service therefore validates the signed message, persists the exact signed bytes and signature before broadcasting, and only retries those same bytes.
- [Turnkey Solana support](https://docs.turnkey.com/features/networks/solana): Turnkey supports SPL Token and Token-2022 transactions and provides a Solana transaction parser for policy checks.
- [Turnkey Solana policy examples](https://docs.turnkey.com/features/policies/examples/solana): Turnkey policies can constrain SPL transfers by source owner, token mint, destination token account, and atomic-unit amount. `TransferChecked` is needed for policies to inspect the mint. The signer service constructs exactly one `TransferChecked` instruction and does not create recipient token accounts.
